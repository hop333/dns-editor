Self-hosted DNS zone editor

A small web panel for managing BIND zones, checking records before saving, reloading BIND, and enabling DNSSEC without editing zone files by hand.

Install guide View source 
curl -fsSL https://raw.githubusercontent.com/OWNER/dns-editor/main/deploy/install.sh \
      | sudo bash -s -- \
      --repo https://github.com/OWNER/dns-editor.git \
      --domain dns.example.com \
      --site-domain example.com \
      --email admin@example.com

Runs on your VPS

BIND, API, UI, and HTTPS reverse proxy are packaged with Docker Compose.

Zone validation

Records are saved only after server-side validation and `named-checkzone`.

DNSSEC workflow

Enable signing, reload the zone, copy DS records, and finish setup at the registrar.
