# Сайт проекта

Каталог `site/` содержит небольшую статическую страницу проекта. Её можно разместить через GitHub Pages, nginx, Caddy или любой другой static hosting.

Рекомендуемая структура сайта:

- `/` - что такое проект и зачем он нужен;
- `/install` - команда установки и требования;
- `/demo` - скриншоты и тестовый сценарий;
- `/dnssec` - объяснение работы DNSSEC;
- `/security` - модель безопасности;
- `/github` - ссылка на репозиторий.

Для первого публичного релиза сайт лучше держать документационным. Главный продукт проекта - сама DNS-панель, а не маркетинговый лендинг.
